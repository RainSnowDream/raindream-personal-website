背景音乐放在这个文件夹里，歌单由 playlist.json 决定。

=== 新增音乐三步 ===

第 1 步：把音乐文件复制进本文件夹。
         文件名用全小写英文 + 连字符，例如 my-song.mp3
         （别用中文 / 日文 / 空格做文件名，网址里会被编码，容易出坑）

第 2 步：用记事本打开 playlist.json，在方括号里加一条：

    { "src": "audio/my-song.mp3", "title": "歌名", "artist": "歌手" }

         src    必填，必须和第 1 步的文件名一模一样
         title  不写就显示文件名
         artist 不写就不显示
         default: true 表示默认曲（整表只写一条）—— 访客点播放先从它开始

第 3 步：保存。数组的顺序就是列表的顺序，想调顺序就把这几行上下移动。

=== 播放规则 ===

顺序随机（可在网页上切换成顺序播放）；「上一首」按播放历史回退。
访客一进网站就会在后台把整个歌单下载好（现在共 65 MiB）——
慢网（2G/3G）和「节省流量」模式会自动跳过，那时点哪首都能边下边播。
下载失败或超过 30 秒会自动重试（最多 3 次）。

如果访客点了还没下载完的那首：**不会没反应，也不会同时播两首** ——
会自动排队，等这首下载完立刻开始播放；中途又点了别的，就只听最后一次点的那首。
歌名后面的小图标：✓ 已下载可播放、转圈 下载中、! 下载失败。

注意：
- 单首不能超过 25 MiB（Cloudflare 静态资源上限）
- 想减少访客流量：把 MP3 转成 128 kbps（当背景音乐听不出差别），
  总量能从 65 MB 降到约 26 MB；文件名不变就不用改 json
- 这个 README.txt 本身不会上传到网站（已写进 .assetsignore）
