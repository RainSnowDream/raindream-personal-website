背景音乐放在这个文件夹里。歌单有三种来源，按优先级：

【推荐】建一个 playlist.json，可以写真实歌名（想显示中文歌名就用这个）：

    [
      { "src": "audio/bgm-1.mp3", "title": "歌名一", "artist": "歌手" },
      { "src": "audio/bgm-2.mp3", "title": "歌名二" }
    ]

  src 必填；title 不写就显示文件名；artist 可以省略。

【其次】按编号命名，不用建 json（列表里显示「第 N 首」）：

    bgm-1.mp3、bgm-2.mp3、bgm-3.mp3……  编号必须连续，最多 30 首

【最后】单曲：命名为 bgm.mp3

播放规则：顺序随机，一首放完随机换下一首；「上一首」按播放历史回退。

注意：
- 编号必须连续：有 1、2、4 却没有 3，就只会放到第 2 首
- 单首不能超过 25 MiB（Cloudflare 静态资源上限）；建议 MP3、128 kbps 左右
- 文件名用小写英文，避免网址编码问题
- 这个 README.txt 本身不会上传到网站（已写进 .assetsignore）
